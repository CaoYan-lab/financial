# 长富桌面客户端

长富采用原生双端工程，共享 `../changfu-contracts` 协议，不共享 UI 或券商 SDK 运行时代码。

- `macos/`：首发客户端，SwiftUI/AppKit + Objective-C++ Futu C++ 适配层。
- `windows/`：第二阶段客户端，WPF/.NET 8 + Futu C# 适配层。
- `docs/`：桌面端安全边界和平台实现说明。

## 固定边界

1. OpenD 仅允许连接 `127.0.0.1:11111`。
2. 后台返回的订单意图不是执行许可；客户端必须验签、校验租约、重拉数据并由用户确认。
3. 券商密码、交易解锁信息和设备私钥不得离开本机。
4. A 股和 Longbridge 首期只显示“规划中”，不得展示伪数据。
