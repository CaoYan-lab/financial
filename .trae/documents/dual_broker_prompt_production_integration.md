# 双券商新版提示词生产接入

## 边界

本次接入真实服务调用路径，默认保留旧版。只提供 `legacy` 和 `shadow` 两种模式，暂不提供新版实盘执行模式。不是继续用合成数据测试，也不是启用自动交易。

开启shadow后，该角色改用真实上下文调用新版，保存完整输出、版本、输入摘要、证据及校验结果，但单票返回不批准的HOLD、组合返回无晋级结果、挂单不发出撤单授权。旧版不会在shadow失败后兜底执行，避免失败开放。

这是替代该角色的只读模式，不是并发运行旧版自动交易的旁路。全部角色启用shadow时不会产生新的可执行候选；组合可评估启用前已有候选，不能把无候选时未调用误报为组合通过。现有人工操作和独立挂单硬规则不受此开关控制。

## 开关

`TRADING_PROMPT_MODE=legacy|shadow` 全局默认；`LONGBRIDGE_PROMPT_MODE`、`FUTU_PROMPT_MODE`覆盖全局；`LONGBRIDGE_SINGLE_PROMPT_MODE`、`LONGBRIDGE_PORTFOLIO_PROMPT_MODE`、`LONGBRIDGE_MANAGED_PROMPT_MODE`及对应FUTU角色开关优先。非法值失败关闭，不落回旧版。

仅显式传入broker的美股/港股服务使用新版分支；共享组合服务的A股TradingAgents调用不受影响。多租户长桥通过现有服务入口接入，不读取其他租户数据。

## 真实数据与契约

- 输入来自调用方账户、该标的缓存行情与趋势、现有策略配置、持仓及已知订单；不导入scripts/shadow或固定测试价格/预算。
- 来源时间不改写为当前时间；缺少时间或币种不匹配标为未知。
- 长桥融资字段按已有规则规范化；富途目前未提供同等可靠原始融资等级时标为UNKNOWN，不套用长桥编码。
- 无完整组合风险预留账本时可用风险预算为未知，不以购买力代替亏损预算，不将持仓/订单缺失风险视为0。
- 使用现有费用估算时标明estimated，非券商确认费用；未给融资/借券成本不得编造为0。
- 候选独立携带自己的报价、时间、趋势、决策与风险方案；旧决策没有失效价/目标/成本资料时保留未知，不凭同分规则强制晋级。
- 模型输出采用严格契约；保留失效价、退出条件、持仓效果、证据编号及跟进动作。元数据由程序绑定，不由模型复述。
- 响应时校验源数据时效，过期记录为需刷新；不把格式通过等同执行许可。当前没有执行模式。
- 审计只写受限本地目录，限制每条大小、数量，记录敏感输入不打入普通日志；日志仅含匿名范围、请求摘要和校验计数。云端临时盘不承诺长期存储。

## 后续执行模式门禁

需要真实富途融资映射、跨进程原子预算预留、订单占用、响应后刷新和最终提交校验，以及独立保留样本测试。止损字段当前只是保留的决策契约，不代表自动创建止损单。完成并另行批准后才可增加实盘模式。

本轮不提交、不推送、不部署、不调用真实交易或撤单。

## 已实现与使用说明

已连接：

- 富途 `requestLiveTradingDecision`、长桥 `requestLongbridgeLiveTradingDecision`。
- 两个单账户引擎和多租户长桥的 `requestLivePortfolioReviewDecision`，显式传券商身份；A股共享调用保持旧逻辑。
- `requestManagedOrderDecisions` 与监管器提供的完整账户快照。只读结果返回空决策集合，不能进入模型自动撤单路径。
- 富途/长桥候选池和多租户候选的独立行情、趋势、决策方案。旧候选缺失字段保持未知；长桥新候选开始保留完整趋势。
- 多租户使用用户与账户绑定构成匿名审计范围；影子组合不写回WATCH/PROMOTED/REVIEW_FAILED等候选状态。

代码：

- `api/live/tradingPromptV2.ts`：模式选择、生产版指令、递归契约校验、模型调用及审计。
- `api/live/tradingPromptContext.ts`：真实上下文适配、候选证据及融资字段。
- `shared/tradingPromptTypes.ts`：可保留的完整输出与程序绑定。

当前模式没有被实际改动。配置示例仅用于后续经确认的只读运行：

```bash
TRADING_PROMPT_MODE=shadow
TRADING_PROMPT_AUDIT_DIR=.data/trading-prompt-shadow
```

设为 `legacy` 回到原流程。环境变量需要在对应进程启动/重启时注入；Web/Worker配置必须一致。开启全局shadow替代的是三类模型决策，不关闭原有人工确认接口、已存在订单及独立确定性硬规则，不能将它当作账户总停机开关。

每个账户最多保留100个审计JSON，每条上限1MiB，文件权限0600、目录0700；普通日志不输出输入或模型原文。文件包含真实账户相关数据，仅供受控检查，不应提交Git或开放匿名下载。云端临时文件需要另外配置持久化才能长期保留。

## 尚未完成的实盘能力

当前是真实调用路径的只读接入，不是完整可交易实现：

- 富途原始融资映射未完成。
- 可平数量不能简单等同总持仓；目前保留未知，不能声称必要减仓真实数据验收已通过。
- 完整组合风险预留、滑点和融资借券成本未接入；风险占用与排名指标为null，不复制合成场景22/30/17272等值。
- 原托管订单未持久化开平仓效果，目前UNKNOWN，不猜测BUY一定开多。
- 新版没有执行模式，也没有创建止损单或基于退出条件的自动执行器。
- 全局shadow不创建可执行候选，所以新候选不会自动串到组合角色。验证组合需使用已有候选或独立只读采样器；空候选不计作验证成功。
- 本生产适配版本为 `dual-broker-production-v2.4-shadow-1`，指令和输入结构不同于合成v2.4，应重新跑真实只读验收，不能沿用32/32结论。
