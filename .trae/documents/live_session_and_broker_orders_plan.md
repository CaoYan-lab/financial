# 实盘交易时段与券商订单清单修正方案

## 目标

1. 保留实盘组合策略开关语义：
   - `legacy_direct`：单票扫描后直接经过硬风控进入待确认或自动提交链路。
   - `candidate_pool`：单票扫描进入候选池，再经组合裁决和硬风控推进。
2. Futu 与 Longbridge 使用一致的美股时段策略。
3. 两个平台都提供独立于“待确认订单”的券商订单清单，可查看券商账户中的全局订单并进入详情。
4. 券商订单详情中的状态、方向、订单类型、交易时段、生命周期事件和常见错误全部显示中文。

## 美股时段矩阵

| 市场状态 | 单票 LLM 评估 | 新建订单 | 订单时段 |
|---|---|---|---|
| 盘中 | 允许 | 允许 | `RTH` |
| 盘前 | 允许 | 允许限价/主动限价 | `ETH` |
| 盘后 | 允许 | 允许限价/主动限价 | `ETH` |
| 夜盘 | 默认跳过；仅在关闭“跳过夜盘评估”开关后允许研究 | 禁止真实下单 | 无 |
| 周末、节假日、休市 | 始终跳过 | 始终禁止 | 无 |
| 状态不可用 | 休市时钟窗口内按休市处理，否则失败关闭 | 禁止 | 无 |

港股继续按现有规则处理：交易时段允许评估和 RTH 订单，午休与休市跳过评估并禁止新订单。

## 提交时复核

订单生成时确定 `RTH` 或 `ETH`，提交前必须再次检查当前市场状态：

- `RTH` 订单只允许盘中提交。
- `ETH` 订单只允许盘前或盘后提交。
- 夜盘、周末、节假日、休市和状态不可用时拒绝提交。
- 拒绝结果留在本地订单详情中，不调用券商下单接口。

## 券商订单清单

### 数据源

- Futu：复用 `history_order_list_query`，支持日期、标的和分页。
- Longbridge：新增 `todayOrders` 与 `historyOrders` 查询，合并去重后按更新时间倒序分页。
- Longbridge 本地开发环境直接连接 SDK，并主动清除继承的 HTTP 代理变量。
- Longbridge 云端 Worker（`CLOUD_MODE=1`）必须通过 `LONGBRIDGE_ORDER_PROXY_URL` 连接订单接口；代理缺失时失败关闭。

### 页面

两个实盘页面增加“券商订单清单”模块。Futu 与长桥页面的订单区统一采用双栏瀑布布局：

- 与待确认订单分开展示。
- 左栏展示历史策略信号，右栏依次展示待确认订单和券商订单清单。
- 券商订单清单不再放在自动撤单模块下方，也不单独占据页面全宽。
- 清单卡片、筛选器、分页和订单项与历史策略信号、待确认订单保持一致的视觉密度。
- 挂单与自动撤单监管框使用与页面一致的圆角线框；Futu 使用橙色操作主题，长桥使用蓝色操作主题，危险撤单操作保留红色。
- 展示订单号、标的、方向、状态、委托/成交数量、委托/成交价、交易时段和更新时间。
- 支持按标的、状态和方向筛选；筛选条件在后端分页前生效。
- 支持翻页与刷新。
- 每条订单均可直接进入组合订单详情。
- 清单默认查询最近 7 天。

### 组合订单详情

- 待确认订单和券商订单共用同一个详情页。
- 详情页通过 `pendingOrderId` 或券商 `orderId` 精确关联。
- 同页展示系统订单详情、券商订单详情、成交记录、费用、券商状态过程和系统监管过程。
- 外部创建、无法关联待确认订单的券商订单仍可查看券商详情，并明确显示“未关联系统订单”。
- 提交失败且券商未生成真实订单时，仍展示完整系统订单、信号、风控和失败原因。

## 中文化

- 券商状态码、方向、订单类型、有效期、交易时段统一映射为中文。
- Longbridge 详情历史中的英文消息和常见错误码转换为中文。
- Futu 原始枚举不直接显示，前端统一转换。
- 未识别的券商原文保留在技术明细中，但主流程字段必须显示中文说明。

## 验证

- 周末 `CLOSED` 对 Futu、Longbridge 美股均跳过 LLM。
- 夜盘评估开关开启时跳过；关闭时可评估但不得创建或提交真实订单。
- 盘前、盘后生成 `ETH` 订单，盘中生成 `RTH` 订单。
- 提交时段与订单时段不匹配时拒绝。
- Futu 与 Longbridge 券商订单清单可分页并跳转详情。
- 本地 Longbridge 清单和详情直连 SDK 成功；云模式缺少订单代理时明确拒绝。
- 长桥待确认订单和券商订单可跳转同一组合详情，并准确展示关联关系。
- 长桥券商订单筛选在分页前执行，翻页时保留筛选条件。
- 失败订单仍可查看本地详情。
