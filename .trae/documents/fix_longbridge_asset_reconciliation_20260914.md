# 长桥账户资产对账口径修复

## 问题

主账户工作台展示了账户净资产、现金可用、最大购买力和风险等级，但没有展示
Longbridge SDK 返回的 `totalCash`。用户将 `availableCash` 与持仓市值相加时，
结果无法与净资产对平。

## 根因

- `totalCash` 是账户现金余额，用于和持仓市值核对净资产。
- `availableCash` 是扣除融资、冻结等占用后的可用现金，可以为负数。
- 主账户全局适配器遗漏了 `total_cash`，租户适配器则已经返回该字段，两条链路
  的展示口径不一致。

## 修复

1. 主账户资产卡片新增“账户现金”，读取 `total_cash`。
2. “现金可用”明确标注为扣除融资与冻结占用后的可用现金。
3. 缺少 `total_cash` 时显示不可用，不再以 `available_cash` 冒充账户现金。
4. 租户工作台同步统一字段说明。

## 对账关系

正常情况下：

`账户净资产 ≈ 账户现金 + 持仓市值`

报价时间差、未结算费用或其他非证券资产可能产生小额差异。现金可用和最大购买力
属于交易能力指标，不参与上述加总。

## 融资成因与风控口径

2026-09-14 实时只读快照显示：

- 账户净资产：14,473.52 美元
- 账户现金：12,761.07 美元
- 港元可用现金：103,000.00 港元
- 美元可用现金：-378.81 美元
- 美元未结算现金：-1,728.30 美元
- 已用融资：378.81 美元
- 风险等级：0，追加保证金：0

当日 SNDU 买入、卖出和 GOOG 买入产生的美元未结算净支出为 1,728.30 美元。
交易前美元可用现金约为 1,349.49 美元，因此 GOOG 买入后出现 378.81 美元缺口。
账户虽然持有足够港元，但港元没有在买入美股前兑换成美元，券商以美元融资补足了
缺口。这不是总资产超额，而是交易币种现金不足。

模型与硬风控使用以下口径：

1. 净资产用于组合最大亏损预算和单笔最大亏损预算。
2. 账户现金用于资产对账和现金比例，不作为美元订单的可花额度。
3. 允许港元、美元之间的跨币种融资；同币种可用现金只展示当前币种资金与融资
   状态，不单独阻断开仓。
4. 按订单交易币种折算后的账户总现金作为买入上限，最大购买力仍作为更外层上限。
5. 后端最终校验必须保证买入金额加预估费用不超过折算账户现金，不能只依赖模型
   判断。

## 实际下单链路验证

- 主账户确认提交：账户刷新后执行账户现金买入上限，超额时不会调用券商提交函数。
- 多租户 Worker 提交：读取租户最新账户后执行相同校验，资金不足时不会启动订单
  子进程。
- 当前真实账户口径：美元可用现金为负不会单独阻断；只要折算账户现金足以覆盖
  订单金额和预估费用，且融资风险与购买力门禁通过，就允许跨币种融资买入。
- 验证过程未向券商提交或撤销任何真实订单。
