LLM CONFIG

大模型配置

这一块保持 A 股实盘页现有排版：模型、并发、连续竞价 Gate 和保存按钮在 LLM CONFIG 卡片内；右侧固定是实盘门禁。

GUARDRAILS

实盘门禁

SELL_SHORT 在 schema 和硬风控层面禁止。
Trading Agent 只能输出 HOLD / BUY / SELL_TO_CLOSE。
最终裁决仍必须经过 A 股 session gate、readiness gate 和人工确认。
A-SHARE TRADE STRATEGY

A股策略与提示词版本

这是 A 股实盘页中 LLM CONFIG + GUARDRAILS 后面的独立整行模块。Trading Agent 在这里作为第三个 executionMode，不新增一级入口，也不挪出实盘链路。

当前：Trading Agent 实验
legacy_direct

大模型直推

单票 LLM 决策直接进入 A 股硬风控；通过后进入待确认订单。适合最快速地形成交易建议。

candidate_pool

候选池组合裁决

非 HOLD 先进入候选池，再由组合裁决比较多票优先级。适合解决“买哪个、先买哪个”。

trading_agent

Trading Agent 实验

多角色 Agent 研究链输出最终裁决。非 HOLD 不进入候选池，直接走 Agent 裁决后的硬风控。

TRADING AGENT PIPELINE

多角色 Agent 研究链

第一版不引入 Python LangGraph；在 A 股模块内实现轻量 pipeline，每个阶段都可记录、可展示、可失败、可跳过。

agentRunId: ashare-agent-20260628-001
1

Market Analyst

读取 120 根 1m K线、tickerPoints、盘口和 quote，判断短线结构、成交活跃度、盘口压力。

2

Risk Analyst

检查 A 股交易规则、涨跌幅约束、流动性、波动、连续竞价和 SELL_SHORT 禁止。

3

Bull Researcher

给出为什么现在可以买入或平仓卖出的正向论据，明确触发条件和价格区间。

4

Bear Researcher

给出为什么不该交易、为什么可能是噪声、为什么应该继续 HOLD 的反方论据。

5

Portfolio Manager

综合所有报告，输出 HOLD / BUY / SELL_TO_CLOSE、数量、价格、置信度和风险说明。
